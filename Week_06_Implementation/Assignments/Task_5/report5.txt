Použitý AI model : gpt 5-6 luna

Platný API kľúč pre Week 6 nebol k dispozícii a starý kľúč z Week 4 už
nefungoval. Preto skript nepoužíval OpenAI API priamo. Použil manuálny
postup: solving.py automaticky vytvoril retrieval query a prompt, používateľ
prompt vložil do nového chatu, odpoveď skopíroval späť do terminálu a ukončil
ju riadkom __END__.

Tento variant automatizuje RAG vyhľadávanie, prípravu promptu, kontrolu
syntaxe, zápis a testovanie, ale odovzdanie promptu a odpovede medzi Python
skriptom a chatom je manuálne.

Skript používa lokálny model
sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2 na vytvorenie
embeddingu vyhľadávacieho textu. Tento model je rovnaký ako pri Task 3.
Vyhľadávací text obsahuje názov triedy, metódy, cestu k súboru a opis úlohy.
Z embeddings.jsonl sa načítajú uložené vektory a texty. Pre každý záznam sa
vypočíta skalárny súčin s embeddingom úlohy.Záznamy sa
zoradia zostupne podľa skóre a do promptu sa vloží top 5.

Prompt pre každú úlohu obsahoval:
názov cieľového súboru, triedy a metódy a jej docstring,
celý aktuálny cieľový Python súbor,
päť najpodobnejších chunkov vrátane identifikátora, indexu časti, skóre
podobnosti a textu,
pokyn zachovať signatúru, dekorátory a docstring a vrátiť iba telo metódy.

Po prijatí odpovede skript odstránil spoločné odsadenie, overil Python syntax
pomocou ast a nahradil iba pass placeholder.
zdrojové súbory sa nezapisovali priebežne. Po dokončení všetkých desiatich
úloh skript vypísal zoznam súborov a vyžiadal si
potvrdenie. Používateľ potvrdil zápis zadaním y. Následne sa spustili
unittesty.

Nasledujúci prehľad zaznamenáva správanie požadované v promptoch a telo
metódy, ktoré bolo vložené do klonovaného repozitára. Niektoré úlohy mali
v promptoch doplnené aj konkrétne očakávania z existujúcich testov, pretože
päť najrelevantnejších chunkov nemuselo obsahovať všetky okrajové prípady.

4.8 BulkDiscountPricing.price – pricing.py

Dodatočný kontext testov: quantity sa sčíta naprieč položkami. Ak celkové
množstvo nedosiahne threshold, vráti sa cena základnej stratégie. Pri
dosiahnutí threshold sa percentuálna zľava uplatní na výslednú cenu
základnej stratégie vrátane prípadnej dane. Zľava sa počíta v centoch
s celočíselným zaokrúhlením nadol; stopercentná zľava vráti Money(0).

Vložené telo:

    total_quantity = sum(item.quantity for item in items)
    base_price = self._base.price(items)

    if total_quantity < self._threshold:
        return base_price
    if self._percent_off == 100:
        return Money(0)

    discount = base_price.cents * self._percent_off // 100
    return Money(base_price.cents - discount)
